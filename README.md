# 紙面工房

社報・イベントフライヤー・お知らせを A4 で作れる Web アプリです。
サーバー側のプログラムやデータベースは不要で、このフォルダのファイルを置くだけで動きます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（画面・機能すべて） |
| manifest.webmanifest | スマホやPCに「アプリとしてインストール」するための設定 |
| sw.js | 一度開けばオフラインでも使えるようにする仕組み |
| icon.svg / icon-192.png / icon-512.png | アプリのアイコン |

## 使い方（3通り）

### 1. パソコンでそのまま開く（いちばん簡単）
`index.html` をダブルクリックして Chrome / Edge で開きます。
編集・PNG/PDF 書き出し・印刷・作業ファイルの保存はすべて使えます。
（この方法ではアプリとしてのインストールとオフライン対応は使えません）

### 2. 社内やネットで公開して、みんなで使う
このフォルダを丸ごと Web サーバーに置くだけです。https で公開すると、
Chrome / Edge のアドレスバーの「インストール」ボタンからデスクトップアプリとして使えます。

無料で公開できる例:
- **Netlify Drop**（https://app.netlify.com/drop）: フォルダをドラッグ＆ドロップするだけで URL が発行されます
- **GitHub Pages**: リポジトリにファイルを置いて Pages を有効にします
- 社内の Web サーバー / NAS の Web 公開機能

### 3. 手元で試しに動かす
```
python -m http.server 8765
```
を このフォルダで実行し、ブラウザで http://localhost:8765 を開きます。

## データの保存について
- 編集内容は **使っているブラウザの中** に自動保存されます（サーバーには送られません）。
- 別のパソコンで続きを編集するときは「作業ファイルを保存」で .json を書き出し、
  移動先で「作業ファイルを開く」で読み込みます。

## 必要な通信
初回表示時に次のサイトから読み込みます（インターネット接続が必要）。
- Google Fonts（書体）
- cdnjs.cloudflare.com（html2canvas：画像書き出し、jsPDF：PDF書き出し）
